# Code-generated figures

This directory contains publication-resolution PNG and vector PDF outputs for
figures generated by the scripts in `scripts/figures/`.

- `main_figures/`: Figs. 1–3 and 5;
- `supplementary_figures/`: Figs. S1–S4, including two page-sized versions of
  Fig. S4.

Fig. 4 is an independently prepared system-architecture schematic and Fig. S5
contains interface screenshots; neither is generated by the analysis code and
neither is included in this repository.
