# Aggregate reference results

This directory contains non-participant-level outputs generated by the
analysis scripts:

- `primary/`: primary mixed-effects model contrasts, difficulty effects and
  convergence diagnostics;
- `length_adjusted/`: response-length-adjusted sensitivity results;
- `descriptive/`: PCA, response-length and standardized-score summaries;
- `difficulty/`: estimated marginal means used for Figs. 3 and S4.

These files are included as reference outputs. Running `run_all.py` with the
restricted analysis-ready dataset regenerates them. No participant-level
ratings, response text or direct identifiers are included here.
